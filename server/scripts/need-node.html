還差一步：安裝 Node.js

小倆口伺服器是用 Node.js 寫的，這台電腦需要先安裝它（免費，大約 2 分鐘）。

  1. 打開 Node.js 官網，下載標示 LTS 的安裝程式（Windows 選 .msi，Mac 選 .pkg）。
    前往 Node.js 下載頁
  2. 打開下載的安裝程式，一路按「Next／繼續」直到完成。
    出現「Tools for Native Modules」的勾選框時不用勾。
  3. 回到小倆口的資料夾，再雙擊一次 start-windows.bat（Mac 是 start-mac.command）。

接下來如果還沒裝 PostgreSQL 資料庫，啟動程式會再打開下一份說明。
