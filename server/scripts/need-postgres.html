安裝 PostgreSQL 資料庫

你們的位置、心情、帳本都會存在這台電腦的 PostgreSQL 資料庫裡（免費，大約 5 分鐘）。

Windows

  1. 打開下載頁，在最新版本那一列選 Windows x86-64 下載。
    前往 PostgreSQL 下載頁
  2. 打開安裝程式，一路按「Next」。要你設定 Password 的那一頁，輸入一組密碼並記下來。
    🔑 等一下小倆口會問一次這組密碼
  3. Port 保持 5432，其他都用預設值。最後一頁的「Stack Builder」不用勾，直接按 Finish。
  4. 回到小倆口的資料夾，再雙擊一次 start-windows.bat，照著畫面輸入剛剛的密碼就完成了。

Mac

  1. 下載 Postgres.app，拖進「應用程式」資料夾。
    前往 Postgres.app
  2. 打開 Postgres.app，按「Initialize」。左上角大象圖示亮起來就代表在執行了。
  3. 再雙擊一次 start-mac.command。Postgres.app 不需要密碼，會自動設定好；跳出詢問是否允許連線的視窗時，按「OK」。

Linux

  1. 用套件管理員安裝，例如 sudo apt install postgresql。
  2. 幫管理員設定密碼：sudo -u postgres psql -c "\password postgres"
  3. 執行 ./start-linux.sh，輸入剛剛的密碼。
    Fedora／RHEL：先把 pg_hba.conf 裡 127.0.0.1/32 與 ::1/128 的 ident 改成 scram-sha-256，再 sudo systemctl reload postgresql。

已經裝過 PostgreSQL 但忘記密碼？請看說明文件 docs/SELF_HOSTING.md 的「疑難排解」。
